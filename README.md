# SHU-CSlearning

本人本科期间在上大计科专业的学习资料收集与分享 用于交流分享~ 仅供参考

==观前须知==：由于本仓库开设的最初目的是对一些课程的大概学习路线、学习内容有大致了解/对实验的内容提供提前预习、熟悉的方式，而不是提供一个“抄写”作业的途径（这是对于大家的**不负责**，也是对于认真完成作业的**不公平**）（虽然有一些课程确实没有必要花费过多的时间，但是对于这些课程的了解以及自我认识还是需要有的）

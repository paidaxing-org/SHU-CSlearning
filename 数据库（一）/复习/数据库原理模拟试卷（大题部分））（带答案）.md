#### **六、综合题（共 15 分）**

**场景描述：**

某工厂需要建立一个管理系统。涉及以下实体：

- **零件**：零件号（PNO）、名称、规格、单价。

2. 将该 E-R 图转换为**关系模式**，并标明主键和外键。
3. 请写出创建“供应关系”对应表的 **SQL 语句**（要求包含实体完整性和参照完整性约束）。

### **参考答案**

#### **四、应用题**

1. **SQL:**

   SQL

   ```
   UPDATE SC SET GRADE = GRADE * 1.1 
   WHERE CNO IN (SELECT CNO FROM C WHERE CNAME = 'Database')
     AND SNO IN (SELECT SNO FROM S WHERE SDEPT = 'CS');
   ```

2. **SQL:**

   SQL

   ```
   SELECT SNAME FROM S WHERE NOT EXISTS (
       SELECT * FROM C WHERE TEACHER = '王平' AND NOT EXISTS (
           SELECT * FROM SC WHERE SNO = S.SNO AND CNO = C.CNO
       )
   );
   ```

3. **SQL:**

   SQL

   ```
   ALTER TABLE S ADD CLASS_RANK CHAR(10);
   UPDATE S SET CLASS_RANK = 'Superior'
   WHERE SNO IN (SELECT SNO FROM SC GROUP BY SNO HAVING AVG(GRADE) > 90);
   ```

4. **关系代数:** $\pi_{SNO, SNAME}(\sigma_{CNO='C01' \wedge GRADE > 85}(S \bowtie SC))$

5. **关系代数:** $\pi_{SNO}(SC \bowtie \pi_{CNO}(\sigma_{CPNO='C02'}(C)))$

6. **方式一:** $\pi_{SNO}(\sigma_{CNO='C01'}(SC)) \cup \pi_{SNO}(\sigma_{CNO='C02'}(SC))$

   **方式二:** $\pi_{SNO}(\sigma_{CNO='C01' \vee CNO='C02'}(SC))$

#### **五、简答题**

1. **语义描述**：查询计算机系（CS）中成绩在 90 分以上的学生姓名及其对应的课程名称。
2. **初始语法树**：根节点为投影($\pi$)，中间节点为选择($\sigma$)，下方为三个关系的笛卡尔积或连接。
3. **优化语法树**：将选择条件 $SDEPT = 'CS'$ 移至 $S$ 关系上方，将 $GRADE > 90$ 移至 $SC$ 关系上方，然后再进行连接运算，最后投影。

#### **六、综合题**

1. **E-R 图**：三个实体（零件、项目、供应商），一个多对多对多（m:n:p）的联系“供应”，供应数量作为联系属性。

2. **关系模式**：

   - 零件(PNO, 名称, 规格, 单价) PK: PNO
   - 项目(JNO, 项目名称, 预算) PK: JNO
   - 供应商(SNO, 名称, 城市) PK: SNO
   - 供应(SNO, PNO, JNO, 数量) PK: (SNO, PNO, JNO); FK: SNO, PNO, JNO

3. **SQL:**

   SQL

   ```
   CREATE TABLE Supply (
       SNO CHAR(10),
       PNO CHAR(10),
       JNO CHAR(10),
       QTY INT,
       PRIMARY KEY (SNO, PNO, JNO),
       FOREIGN KEY (SNO) REFERENCES Supplier(SNO),
       FOREIGN KEY (PNO) REFERENCES Part(PNO),
       FOREIGN KEY (JNO) REFERENCES Project(JNO)
   );
   ```
